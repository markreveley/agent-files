# Adversarial audit, 2026-11-02 (before trial day 1)

Five parallel read-only audits: parser, runner and backends, hook/stats/install, Neovim plugin, and docs. Baseline at the time: 70 unit tests, 44 Neovim checks, smoke S1-S5 all green. None of the findings below is caught by an existing test.

**Evidence codes.** R = the auditor reproduced it (scripts are in that session's scratchpad, now gone). V = the lead checked it against the code. RO = the auditor only read the code. Fix the A list before the trial starts: those findings skew H1-H3, wedge threads, or cost money. Delete each item once it is fixed and has a test.

## A. Fix before day 1

1. **`claude-cli` turns bill the API.** `backends/claude_cli.py:47` passes the whole environment to `claude`, including `ANTHROPIC_API_KEY`, which operator step 1 says to export. With that key set, `claude -p` uses it instead of the plan. Strip `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN` from the child's environment. (V for the env; the billing behaviour comes from Claude Code's auth docs and was not run.)
2. **Concurrent git commits fail silently.** `watch` runs each thread on its own thread (`runner.py:476`), and `git.commit` (`git.py:21-32`) has no lock and logs nothing. 8 pending threads at start-up gave 1/8 send commits. A lost send commit is a context edit H1 never sees. Fix: a process-wide lock around commit, and log failures as the spec says. (R twice, V)
3. **Threads wedged by an `END` written inside a fence.** In each case the agent turn parses as still open, `is_send` stays false, and `recover` skips the thread because its status isn't `working`:
   - `runner.py:320` `END (conflict)`: no fence balancing (R, V).
   - `runner.py:416` recovery `END (interrupted)`: no fence balancing (R, V).
   - `runner.py:344` `rfind("## agent · tN\n")` also matches an escaped `\## agent · tN` in the model's text, so balancing starts from the wrong line (R).

   Fix: one close helper that all three paths use, with the header match anchored to a line start. Add a test that each path leaves the turn closed.
4. **A bare `\r` in model output.** `on_text` (`runner.py:227-236`) splits on `\n` only, while `read()` and `parse_file` read with universal newlines. Two effects: any `\r` (CRLF included) makes `check_foreign` (`runner.py:207`) see a false conflict; and a bare `\r` before `END` or `## you · tN` gets past `escape_line`, so the model can close its own turn or inject a user turn. Fix: normalise `\r\n` and `\r` to `\n` in `on_text`. (R for the injection; the false conflict is V by reading.)
5. **Stats skews H1.**
   - `stats:41-57`: deleting a failed or interrupted agent turn to retry it counts as a context edit (R, V). m1-plan H1 means deliberate edits that help.
   - `stats:156`: the percentage is rounded before it is compared with the 5% and 20% thresholds (1/21 prints 5%; 8/41 prints 20%) (V).
   - `stats:84`: git reads `--since YYYY-MM-DD` as that date at the current time of day (R, V). Also, the 6+ denominator ignores `--since`.
   - Renames: renaming a thread after an edit drops the edit (stats:120-124). A fork renamed after an edit counts twice (stats:95,111) (R).
6. **Spend isn't recorded for stopped, conflicted or failed turns.** A STOP leaves `info={}` (`runner.py:297`), and `BackendError` from the anthropic and claude_cli backends carries no partial usage, so no `response.json` is written. Input tokens are billed anyway, and the cap underprotects. (R, V)
7. **Neovim plugin:**
   - `init.lua:127-129`: if the buffer's last turn is an open agent turn, `capture_draft` takes the whole buffer (`from = 1`) and re-appends it on every reload. Typing just after `:AgentsSend` gave 192 lines against 31 on disk, and a later `:w` writes the duplicates (R, V).
   - `init.lua:41-62`: a stale `working` status (the runner died) keeps the buffer read-only for good, and the spinner re-locks it every 120 ms (R, V). Use `S.mark`'s stale word.
   - `display.lua:91-99`: `vim.wo.*` behaves like `:set`, so `foldexpr`, `foldlevel=0`, `conceallevel` and `wrap` leak into every later window (R, V). Use `vim.wo[win][0]` / `setlocal`.
   - `init.lua:175-178`: writing `seen` fires the directory watcher, which writes `seen` again, at about 9 Hz (29% CPU idle on a 5k-line thread) (R).
   - `init.lua:198-201`: the debounce restarts on every event, so a reply streaming faster than 100 ms per line never shows live (R).
8. **Hook command path.** `install.sh:21` prints the bare `agent-files-hook`. Print `$HOME/.local/bin/agent-files-hook` so the hook doesn't depend on the PATH Claude Code was started with (R under `env -i`; not tried in live Claude Code).

## C. Edge cases (fix when convenient, or record as known)

- **Parser:**
  - frontmatter keeps inline `# comments` in values (`thread.py:94-103`), e.g. `runtime: direct  # x` isn't direct;
  - a UTF-8 BOM hides the frontmatter (`thread.py:290`, use `utf-8-sig`);
  - Lua patterns `^%s*(.-)%s*$` and `gsub("%s+$")` are quadratic on long whitespace runs (40k spaces take 9.8 s, on every keystroke);
  - Python strips Unicode whitespace and Lua doesn't (NBSP fences, `END<NBSP>`);
  - `## carry` after stray text differs between the two parsers;
  - `escape_carry` in `init.lua:308-314` lacks `\b` and re-escapes lines that are already escaped.
- **Runner:**
  - `output_config.effort` is sent to every model (`anthropic.py:13`); older Haiku and Sonnet 4.5 reject it (RO);
  - bad UTF-8 in any `thread.md` crashes `watch` (`UnicodeDecodeError` isn't an `OSError`, `runner.py:129-135,405-408`);
  - `claude_cli` treats a nonzero exit with no `result` event as `done`, and has no timeout, so STOP waits on the child; it has no tests;
  - `spend_today` uses file mtime (a clone or checkout puts old spend on today);
  - a bad TOML makes `once` exit 0 (the spec says 1);
  - a quoted price raises `TypeError` after `END`.
- **Hook:**
  - the observed directory is keyed by the basename of `cwd`, and `cwd` follows `cd`, which orphans a `working` directory;
  - `SessionStart` with source `compact` sets `done` mid-turn;
  - `PermissionDenied` isn't registered, so the status stays `blocked`;
  - `session_id` isn't validated (`../..` can delete `threads/`; real UUIDs can't);
  - the hook and grep don't enforce D1 (they don't refuse a code-checkout root).
- **Grep:** it logs failed searches; a pattern containing a newline logs two lines.
- **Plugin:**
  - an observed buffer becomes modifiable after the first hook write (`init.lua:169-171`);
  - each reload is an undo step (set `undoreload=0`);
  - `:AgentsNew .` and `:AgentsNew ..` are accepted;
  - `:bd` doesn't detach;
  - a missing `agent-files-grep` raises E475;
  - a model-written `▸` line can fold real content.
- **Smoke:** S2-S5 assert less than their names claim (the runner does the right thing; the asserts are thin).
